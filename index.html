Memuat...
"Setoran Sebelumnya (Periode Berjalan)" = hutang dari periode setoran SEBELUM periode saat ini (setoran cuma 2x seminggu: Rabu & Sabtu), dihitung sekali per periode. "Komisi Belum Terbayar" hanya untuk Korlap, otomatis muncul tiap ada omset Teknisi, dan balik ke 0 begitu owner sudah bayar/lunas.

Input Transaksi

Setoran (-): Rp 0
Komisi Korlap (5% omset teknisi): -
Jumlah Setoran (perkiraan): Rp 0
Setoran sebelumnya (hutang periode sebelumnya) dihitung otomatis oleh sistem saat disimpan, dan ditampilkan di tab Karyawan & Ringkasan.

Edit Karyawan

Otomatis ter-update tiap kali input nominal transfer/pembayaran setoran. Positif = dia masih hutang ke owner, negatif = owner hutang ke dia.
